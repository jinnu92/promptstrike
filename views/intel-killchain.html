📖 Researcher's Guide: Promptware Kill Chain

Description: The Promptware Kill Chain maps the stages of an LLM exploit, from initial reconnaissance to full system persistence. Identifying the current stage helps security teams understand the depth of a model's compromise.

How to Test:
1. Execute: Run a complex, multi-step attack against an AI agent.
2. Capture: Take the most recent response from the model.
3. Analyze: Paste it here to see if the model has moved from "Reconnaissance" (asking about tools) to "Exfiltration" (actually using tools to send data).

Mitigation:
• Inter-stage Monitoring: Log and analyze every tool call for patterns that match early-stage kill chain behaviors.
• Permission Gating: Do not allow an agent to use high-privilege tools if its previous actions suggest it is in a "Reconnaissance" phase.
• State Reset: Regularly clear conversation history for autonomous agents to prevent "Persistence" and long-term compromise.
