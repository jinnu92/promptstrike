📖 Researcher's Guide

Description: Vision Steganography embeds malicious instructions into image pixels. While humans see a normal image, Vision-Language Models (VLMs) like GPT-4o or Claude 3.5 process these pixels into text, leading to Cross-Modal Prompt Injection.

How to Use:
1. Upload a "Cover Image" (or use a synthetic one).
2. Select a payload (e.g., P-101 System Prompt Extract).
3. Choose a technique: LSB for simple OCR bypass, or FGSM/Attention for advanced neural model hijacking.
4. Export the image and upload it to the target AI. Ask "Describe this image."

Mitigation:
• Lossy Pre-processing: Resize and re-compress images to destroy pixel-level stego.
• Noise Injection: Add Gaussian noise to disrupt adversarial perturbations.
• OCR Scrubbing: Run independent OCR and check for command-like strings before VLM processing.
