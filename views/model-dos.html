📖 Resource Exhaustion Payload
📖 Researcher's Guide: Model Denial of Service

Description: LLM10 occurs when an attacker crafts inputs that consume excessive compute resources (tokens, memory, or processing time), causing the service to degrade or fail for other users.

How to Test:
  • Monitor latency during 'Recursive Expansion' strikes.
  • Measure memory usage with 'Context Overflow' sequences.
  • Check for 'Infinite Loop' hangs in agentic workflows.
How to Fix:
  • Enforce strict Max Token Limits on both input and output.
  • Implement Request Timeouts and circuit breakers.
  • Rate limit users based on Total Compute Cost, not just requests.
