🛡 Mission Brief: What is PromptStrike?

PromptStrike is an advanced, browser-native red-teaming toolkit designed for testing LLM prompt injection and multi-modal vulnerabilities. It bridges the gap between manual testing and autonomous adversarial simulation.

Built for security researchers, PromptStrike provides a unified laboratory to generate high-fidelity attack vectors (Text, Vision, Audio, MCP) and orchestrate coordinated strike campaigns.

⚔ Tactical Arsenal: Attack Vector Overview
🕵️ Core Jailbreaking
DAN-style roleplay, many-shot context stuffing, and multilingual bypasses. Targets the model's base alignment and safety filters (LLM01).
🌐 Indirect Injection
Poisoning RAG databases and tool-retrieved content. Attacks the model through external data sources it trusts (LLM02).
🧠 Agentic Hijack
Exploiting autonomous agents with tool access. Includes Confused Deputy, Authority Escalation, and MCP protocol attacks (LLM07/08).
👁️ Multimodal Lab
Vision-steganography and frequency-domain audio injections. Targets the cross-modal encoders of VLMs and speech models.
⚠️ Resource Exhaustion
Model Denial of Service (DoS) via recursive expansion, context overflow, and tokenizer stress testing (LLM10).
🛡️ Defense Verification
The Shield: Autonomous stress-testing of your system prompts and safety filters to verify mitigation effectiveness.
