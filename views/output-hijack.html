📖 Researcher's Guide: Insecure Output Handling

Description: LLM02 occurs when an application blindly trusts the output of an LLM and renders it as HTML, Markdown, or JavaScript without sanitization.

How to Test:
  • Inject an XSS payload into the LLM.
  • Observe if the browser executes alert() or attempts a network fetch.
  • Check for 'Automatic Image Loading' via Markdown pixels.
How to Fix:
  • Use libraries like DOMPurify before rendering.
  • Implement a strict Content Security Policy (CSP).
  • Encode LLM output as plain text by default.
