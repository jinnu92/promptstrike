📖 Researcher's Guide: Agentic Vulnerabilities

Description: Agentic vulnerabilities occur when autonomous AI systems (Agents) are given "tools" or "actions" without sufficient security boundaries. Confused Deputy is when an agent is tricked into using its tools on behalf of an attacker. Excessive Agency is when an agent has more power (e.g., shell access) than it needs for its task.

How to Use:
1. Select Scenario: Choose a vector like Confused Deputy (for tool misuse) or Recursive DoS.
2. Set Objective: Select a target payload (e.g., P-4104 Billing Exfil).
3. Generate Vector: Review the "Simulated Tool Call" to see how the agent might be hijacked.
4. Test: Provide the "Incoming Data" to an autonomous agent and see if it triggers the tool automatically.

Mitigation:
• Human-in-the-Loop (HITL): Require manual user approval for high-impact tool calls (email, delete, buy).
• Zero-Trust Architecture: Treat every external input (email, web search result) as untrusted content, not instructions.
• Least Privilege: Use ephemeral sandboxes and restrict tools to the absolute minimum required for the specific task.
