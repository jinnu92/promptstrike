📖 Researcher's Guide: Response Analysis

Description: The Response Analyzer scans AI outputs for indicators of compromise (IoC). It looks for fragments of system instructions, identity disclosures, or unintended data formats (like raw JSON) that suggest a prompt injection was successful.

How to Test:
1. Capture: Copy the full response from the AI model you are testing.
2. Input: Paste it into the "AI Response" box.
3. Context: Select the payload you used to generate that response for better accuracy.
4. Analyze: Click "Analyze Response" to generate a threat score and list of findings.

Mitigation:
• Output Filtering: Use regex-based filters to block common phrases like "My system prompt is" or "As an AI language model."
• Semantic Monitoring: Use a second, smaller model to verify if the primary model's output contains sensitive information.
• Format Enforcement: Strictly enforce output schemas (e.g., only allowing valid Markdown or specific JSON structures).
